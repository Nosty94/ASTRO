# ASTRO HOP · сборка для Яндекс Игр (v19.0)

Однофайловый HTML5-раннер (`index.html`), подготовленный к публикации на платформе
**Яндекс Игры**. Ниже — что улучшено, как проверить и что загрузить в консоль разработчика.

## Быстрый старт

```bash
npm ci                # ставит dev-зависимость (jsdom) для тестов
npm test              # headless-проверка рекламы/монетизации/SDK (72 проверки)
npm run check         # статический релиз-гейт по требованиям платформы (46 проверок)
npm run assets        # генерирует полнокадровую иконку 512×512 для карточки (assets/yandex/)
npm run build         # собирает dist/astro-hop-yandex.zip (архив для консоли)
```

`npm test` и `npm run check` — это «проверка монетизации и рекламы»: они поднимают игру целиком
с подменённым SDK Яндекса, который записывает каждый вызов (`showFullscreenAdv`,
`showRewardedVideo`, `showBannerAdv`, `GameplayAPI.*`, `LoadingAPI.ready`, `payments.*`,
`getLeaderboards`, `auth.openAuthDialog`), и проверяют, что вызовы происходят в правильные
моменты и что награды выдаются только за реально просмотренные ролики.

## Что улучшено в v19.0

### Соответствие требованиям платформы (монетизация и реклама)
- **Game Ready (1.19.2)** — `LoadingAPI.ready()` теперь вызывается один раз и только когда игра
  реально готова (и SDK проинициализирован, и стартовый код отработал).
- **Gameplay-разметка (1.19.3)** — `GameplayAPI.start()/stop()` вызываются строго парами,
  в том числе вокруг любой полноэкранной рекламы и при входе/выходе из меню.
- **Платформенная пауза (1.19.4)** — обработаны события `game_api_pause` / `game_api_resume`.
- **Звук (1.3, 4.7)** — при потере фокуса и на время рекламы звук глушится; после возврата
  музыкальный планировщик больше не «выстреливает» накопленный такт разом.
- **Interstitial (4.4)** — только в логических паузах, минимум раз в 60 с, не раньше 40 с от
  старта и не на первом запуске; никогда не показывается в геймплее.
- **Sticky-баннер (4.6)** — показывается только на экранах-паузах и скрывается на время забега,
  на экране поражения и в паузе (чтобы не перекрывать кнопки «ИГРАТЬ»/«ДАЛЕЕ»).
- **Rewarded (4.5)** — все кнопки с роликами явно объясняют и просмотр, и награду на всех 4 языках;
  награда выдаётся только по `onRewarded`. Добавлены точки: возрождение, ×2 монеты, доп. спин колеса,
  +50 XP батл-пасса, ×2 ежедневная награда, заморозка серии, реролл испытания.
- **Сохранения (1.9, 1.11, 4.2)** — прогресс пишется в localStorage сразу, дублируется в облако
  `Player.setData`, и сохраняется перед показом рекламы (клик по ролику уводит из игры).
- **Автоопределение языка (2.14)** — берётся из `ysdk.environment.i18n.lang`, ручной выбор игрока
  не перезаписывается.

### Новые фичи монетизации
- **Покупки через SDK (1.4, 1.13)** — премиум батл-пасса и наборы монет продаются через
  `ysdk.getPayments()`. Витрина появляется **только** если товар заведён и активен в консоли,
  цена показывается цифрой в валюте портала. Незакрытые покупки дозачисляются и съедаются
  (`consumePurchase`). Без товаров в консоли игра ведёт себя как раньше.
- **Авторизация (1.2.1/1.2.2)** — кнопка «Войти» в профиле (по явному действию, с объяснением
  выгоды). Без входа игра полностью играбельна как гость.
- **Лидерборд** — таблица ТОП-10 и место игрока в профиле; рекорд отправляется через
  `setLeaderboardScore`.
- **Оценка игры (2.13)** — один раз за сессию, после ≥3 забегов, через `ysdk.feedback`.

### Качество и локализация (8.2.3)
- Исправлены отсутствующие переводы: турецкий (+43 ключа), испанский (+34), добавлен ключ `streak`
  во все языки — раньше в профиле рисовалось служебное «streak». Все 4 языка = 280 ключей.
- Исправлена иконка карточки: исходник имел прозрачные скруглённые углы (нарушение 8.3.3) —
  сгенерирован полнокадровый квадрат 512×512 без альфы (`npm run assets`).

## Чек-лист публикации в консоль (games.yandex.ru/console)

1. **Архив**: `npm run build` → загрузите `dist/astro-hop-yandex.zip` (в корне `index.html`,
   имена файлов без пробелов/кириллицы, < 100 МБ — п.1.21/1.22).
2. **Название**: `ASTRO HOP` — одинаково в игре и в карточке (п.5.1.3), без слов
   «бесплатно/лучшая/top» (п.8.2.2).
3. **Иконка**: `assets/yandex/icon-512.png` (512×512, без скруглений/рамок, п.8.3.3).
4. **Скриншоты**: реальный геймплей ≥70% кадра; для портретной ориентации — вертикальные.
5. **Лидерборд**: создайте таблицу с именем `astro_hop_best` (константа `LB_NAME`).
6. **Покупки (опционально)**: заведите товары с id `astro_premium`, `astro_coins_500`,
   `astro_coins_2000`, `astro_coins_5000` — витрина появится сама. Если не заводить — рекламы
   достаточно, покупки скрыты.
7. **Облачные сохранения**: включите опцию «Игра использует облачные сохранения».
8. **Возрастной тег**: 6+ (нет насилия/политики/религии — п.3).
9. Перед отправкой пройдите `npm run check` и `npm test` — оба должны быть зелёными.

### Текст карточки (пример, RU / EN)
- **RU**: «ASTRO HOP — пиксельный раннер по десяти планетам. Прыгай, делай подкаты и рывки,
  собирай комбо и космический режим, сражайся с боссами. Скины, питомцы, батл-пасс и таблица
  лидеров — прогресс сохраняется!»
- **EN**: “ASTRO HOP — a pixel runner across 10 planets. Jump, duck and dash, chain combos into
  Cosmic Mode and fight bosses. Skins, pets, a battle pass and leaderboards — progress is saved!”
- **Как играть**: ТАП — прыжок (два тапа — двойной), СВАЙП ↓ — подкат, СВАЙП ↑ — рывок; на ПК —
  ПРОБЕЛ/↑, ↓, SHIFT.
